## ✨ Características

### 🤖 Backend (Django)
- ✅ API RESTful con Django REST Framework
- ✅ Integración con **Gemini API** para respuestas inteligentes
- ✅ Manejo de sesiones para historial de conversación
- ✅ Configuración por variables de entorno (`.env`)
- ✅ CORS configurado para desarrollo y producción

### 🎨 Frontend (React + Vite)
- ✅ Interfaz moderna con **Tailwind CSS**
- ✅ Indicador de escritura con animaciones
- ✅ Auto-scroll en mensajes
- ✅ Timestamps en conversaciones
- ✅ Optimizado con Vite para carga rápida

### 🔒 Seguridad
- ✅ API Keys gestionadas por variables de entorno
- ✅ CORS configurado correctamente
- ✅ Sin exposición de credenciales en el frontend
